# NanjingMedU-Graduate-Course-Se# 研究生智能选课决策器

一个基于 **Python + Tkinter + Matplotlib + OR-Tools CP-SAT** 的研究生智能选课决策工具。

程序读取培养方案 PDF 和课程安排 Excel，在满足培养方案学分/分组要求、课程时间不冲突等硬性约束的基础上，结合个人的时间、校区、免修、排除及课程偏好，自动生成多个可行选课方案，并提供课程表可视化及多种格式的结果导出。

> **项目定位**
>
> 当前版本主要针对特定研究生培养方案进行了定制，其中部分课程类别、课程分组及分组规则写入了程序代码。因此，它目前更适合作为“可扩展的智能选课框架 + 特定培养方案实现”，而不是适用于所有高校、所有专业的通用培养方案解析器。

---

## ✨ 主要功能

### 1. 培养方案与课程表自动读取

程序支持读取：

- 培养方案 PDF
- 课程目录 Excel（`.xlsx`）
- 课程安排表 Excel

程序会从培养方案中提取课程编号、课程名称、学分、学时、学期等信息，并根据当前程序中的规则进行课程类别和分组识别。

对于培养方案中存在、但当前课程安排表中没有对应课程编号的课程，程序不会擅自猜测真实上课安排，而是将其标记为：

> `网课/待确认`

这样可以避免因为课表缺失而错误地生成具体时间安排。

---

### 2. 课程分组与学分约束

程序支持对培养方案中的课程分组进行约束。

当前版本包含针对特定培养方案设计的分组规则，例如：

- 第 1 组：3 选 1
- 第 2 组：45 选 1
- 第 3 组：选 2 学分
- 第 4 组：选 2–3 学分，至少 2 学分

程序会根据硬性必选课程自动计算剩余所需学分/门数。

对于学分型分组，还加入了“**最小充分集合**”约束：达到培养方案要求后，不会因为优化偏好而继续无必要增加课程。

例如：

> 如果某组在扣除必选课程后还需要 1 学分，而当前可选课程存在两门 1 学分课程，那么程序不会因为“课程越多越好”而同时选择两门。

---

### 3. 课程时间冲突检测

程序将课程时间解析为：

```text
（周次，星期，节次）
```

并通过时间槽约束检测课程冲突。

同一时间槽最多允许一门课程被选择。

支持跨周课程，例如：

```text
1-16周
```

以及类似：

```text
星期一 第7节-第10节
```

的课程安排。

---

### 4. 个人时间限制

用户可以设置希望避开的时间段，例如：

```text
周一7-10；周五下午
```

程序会自动排除与这些时间段冲突的课程班级。

目前支持：

- 指定星期 + 节次范围
- 上午
- 下午
- 晚上

---

### 5. 校区偏好

可以设置：

- 希望校区
- 每周最多去其他校区上课的天数

当前界面提供：

```text
希望校区：
- 江宁校区
- 五台校区
- 随意
```

以及：

```text
每周最多其他校区上课天数：
0 / 1 / 2 / 3
```

当指定了主校区后，程序会将其他校区上课天数作为硬约束，同时在满足约束的情况下进一步优化同一天的校区集中程度。

---

### 6. 课程偏好评分

用户可以对课程进行 0–100 的偏好评分：

| 评分 | 含义 |
|---|---|
| 100 | 必选 |
| 50 | 中性 |
| >50 | 倾向选择 |
| <50 | 不倾向选择 |
| 0 | 强烈不倾向 |

此外，还可以进一步针对**具体班级**设置独立偏好。

例如：

```text
课程：高级生物信息学
课程偏好：80

班级 A：90
班级 B：30
```

程序会综合课程级偏好和班级级偏好进行优化。

---

### 7. 免修课程

可以将课程设置为：

> **免修**

免修课程不需要出现在最终选课方案中，同时程序会相应调整相关分组的最低学分/门数要求。

例如某个分组要求：

```text
至少 4 学分
```

如果其中已经有：

```text
2 学分课程
```

被设置为免修，那么剩余实际需要选择的学分会相应减少。

---

### 8. 不想选择的课程

用户可以直接将课程设置为：

> **不想选**

这属于硬性排除条件。

即使这门课程原本符合培养方案要求，程序也不会选择它；如果该课程同时是培养方案硬性必修课，则程序会进行无解预检查并提示冲突。

---

### 9. 多方案生成

程序可以生成多个不同的可行方案。

可以选择：

```text
5
10
20
50
100
尽可能全部
```

程序不是简单随机抽取几组课程，而是基于约束优化和方案去重机制生成多个候选方案。

方案之间主要根据实际线下课程的：

```text
课程编号 + 班级
```

进行区分。

网课/待确认课程不参与实体课程方案身份判定。

---

### 10. OR-Tools CP-SAT 优化

程序优先使用：

**Google OR-Tools CP-SAT**

进行约束优化。

主要建模内容包括：

- 每门课程最多选择一个班级
- 必修课程必须选择
- 100% 偏好课程作为硬约束
- 课程时间冲突约束
- 培养方案分组学分/门数约束
- 免修课程约束
- 不想选择课程约束
- 避开时间约束
- 校区天数约束
- 同一天校区切换惩罚
- 多方案 no-good / diversity 约束

如果没有安装 OR-Tools，程序会自动使用内置的 DFS + 剪枝回退算法。

> 推荐安装 OR-Tools，因为在课程数量较多时，CP-SAT 通常具有更好的求解性能。

## 🖥️ 程序界面

程序采用 Tkinter GUI。

主要操作区域包括：

### ① 数据文件

选择：

```text
培养方案 PDF
课程目录 Excel
```

读取完成后，程序会自动统计：

- 培养方案课程数量
- 与课表成功匹配的课程数量
- 暂未匹配的课程数量

---

### ② 个人时间 / 校区需求

可以设置：

- 避开时间段
- 希望校区
- 每周最多前往其他校区的天数
- 希望生成的方案数量

---

### ③ 课程偏好

课程列表显示：

- 课程名称
- 课程编号
- 类别/分组
- 学分
- 免修状态
- 不想选状态
- 倾向评分

双击课程后，可以进一步设置课程级和具体班级级偏好。

---

### ④ 方案可视化与特殊需求检查

程序会以周课程表形式显示当前方案，并可以在不同方案和不同周次之间切换。

同时显示：

- 100% 倾向课程是否全部选择
- 免修课程是否全部排除
- 不想选课程是否全部排除
- 避开时间是否满足
- 其他校区天数是否满足

---

## 📤 结果导出

当前版本支持多种结果导出方式：

### 当前方案

可以将当前选中的方案导出为：

```text
CSV
```

### 全部方案

可以将全部生成方案导出为：

```text
JSON
```

JSON 中包含：

- 方案编号
- 目标函数
- 特殊需求检查结果
- 每门课程的详细信息

课程信息包括：

- 课程类别
- 分组
- 分组规则
- 班级名称
- 课程编号
- 课程名称
- 学分
- 原始时间
- 具体日期与时间
- 上课地址
- 校区



### 方案总览

支持：

- 方案总览图
- 总览 PDF
- 总览 CSV

总览 PDF 支持分页，因此当方案较多、课程较多时，可以导出完整 PDF 后再放大查看或打印。

# 📦 安装

## 1. Python 环境

推荐：

```text
Python 3.10+
```

程序使用 Tkinter，因此需要系统提供 Tk 支持。

---

## 2. 安装依赖

进入项目目录：

```bash
pip install -r requirements.txt
```

推荐的 `requirements.txt`：

```txt
pypdf
matplotlib
ortools
```

其中：

- `pypdf`：读取培养方案 PDF
- `matplotlib`：课程表及方案总览可视化
- `ortools`：CP-SAT 约束优化求解器

程序中的 Excel 读取器使用 Python 标准库解析 `.xlsx` 文件，因此不依赖 `pandas` 或 `openpyxl`。

---

# ▶️ 运行

直接运行：

```bash
python course_selector.py
```

也可以通过命令行预先指定输入文件：

```bash
python course_selector.py --pdf your_training_plan.pdf --xlsx your_course_data.xlsx
```

程序支持的命令行参数：

```text
--pdf      培养方案 PDF
--xlsx     课程目录 Excel
```

这两个参数均为可选；如果不提供，程序仍可以启动 GUI，然后手动选择文件。

# 📄 输入文件格式

## 培养方案 PDF

程序需要能够从 PDF 中提取文本。

培养方案中应包含类似：

```text
课程编号
课程名称
学分
学时
学期
```

的信息。

程序会对 PDF 文本进行解析，并根据课程编号及预设规则识别课程类别和分组。

---

## 课程目录 Excel

Excel 文件需要包含相应工作表。

### 工作表：`课程目录`

至少需要包含：

```text
课程编号
课程名称
学分
校区
```

### 工作表：`课程安排表`

至少需要包含：

```text
班级名称
课程编号
课程名称
学分
时间
上课地址
校区
```

程序会根据课程编号将培养方案中的课程与课程安排表进行匹配。

# ⚠️ 当前版本的重要限制

## 1. 培养方案规则存在定制化

目前程序中的课程类别、课程分组主要通过课程编号和特定条件进行识别。

因此：

> **更换学校、专业或培养方案后，不能保证无需修改代码即可直接使用。**

如果希望将项目扩展成通用版本，建议后续将：

```text
课程类别
分组规则
必修课程
特殊课程
```

从 Python 代码中抽离到：

```text
JSON / YAML / Excel / 配置文件
```

中。

这样就可以通过配置文件支持不同学校和专业。

---

## 2. 学期日期目前需要根据学期调整

程序内部包含本学期第一周周一的日期设置。

使用其他学期时，应根据实际教学周调整。

例如：

```python
SEMESTER_WEEK1_MONDAY = dt.date(...)
```

如果未来扩展项目，建议将其改造成 GUI 或配置文件中的可编辑参数。

---

## 3. 缺失课程安排不会被自动猜测

如果培养方案中存在某门课，但课程安排 Excel 中找不到对应课程编号，程序会将其作为：

```text
网课/待确认
```

处理，而不会自行编造时间、地点或班级。

因此，在实际使用时应特别检查：

> “暂未匹配”的课程是否确实应该作为网课或待确认课程处理。

---

## 4. PDF 解析依赖培养方案格式

当前版本的 PDF 解析规则与课程编号格式、培养方案排版有关。

如果更换完全不同格式的培养方案 PDF，可能需要重新调整：

```python
parse_training_plan()
```

函数中的解析逻辑。

# 🧠 算法思路

整体流程可以概括为：

```text
培养方案 PDF
      │
      ▼
课程解析
      │
      ├── 课程类别
      ├── 分组
      ├── 学分
      └── 培养方案规则
      │
      ▼
课程安排 Excel
      │
      ├── 班级
      ├── 时间
      ├── 地点
      └── 校区
      │
      ▼
生成 CourseOption
      │
      ▼
加入个人约束
      │
      ├── 避开时间
      ├── 校区
      ├── 免修
      ├── 不想选
      └── 课程/班级偏好
      │
      ▼
约束求解
      │
      ├── OR-Tools CP-SAT
      │
      └── 无 OR-Tools → DFS + 剪枝
      │
      ▼
多个可行方案
      │
      ▼
课程表可视化
      │
      ├── 当前方案
      ├── 方案总览
      └── 特殊需求检查
      │
      ▼
CSV / JSON / PDF
```
