# 飞书多维表格字段模板

建议按下面字段建立三张核心表。字段名请保持一致，因为程序按字段名写入。

## 培养方案

```text
课程编号      文本
课程名称      文本
学分          数字
课程类别      文本
分组          文本
分组规则      文本
必修          文本
学期          数字
AI解析状态    文本
```

## 课程目录

```text
课程编号      文本
课程名称      文本
学分          数字
校区          文本
来源          文本
```

## 课程班级

```text
班级名称      文本
课程编号      文本
课程名称      文本
学分          数字
时间          文本
上课地址      文本
校区          文本
数据状态      文本
```

> “分组”“必修”“AI解析状态”使用文本也可以，程序会写入兼容的字符串值；“学分”“学期”建议设为数字。
